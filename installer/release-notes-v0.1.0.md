安徽理工大学校园网自动登录客户端。填一次学号和密码，之后开机自动认证、掉线自动重连，平时缩在系统托盘里。

## 下载

| 文件 | 说明 |
| --- | --- |
| `AUSTNET-Setup-0.1.0.exe` | **安装包，推荐。** 装到 `%LOCALAPPDATA%\Programs\AUSTNET`，不需要管理员权限，自带开始菜单项和卸载项，安装时可以勾桌面快捷方式和开机自启 |
| `AUSTNET.exe` | 单文件绿色版。不安装，双击即用，适合放 U 盘或拷给别人临时用 |

两个版本功能完全一样，而且**共用同一份配置**：先用绿色版填过账号，再装安装版打开就是填好的状态。

## 功能

- 自动区分有线 / WiFi，并读出当前 SSID
- 先确认对面是安徽理工大学认证网关再提交账号；不在校园网时不会拿着账号反复试
- 登录结果以网关的 `/drcom/chkstatus` 为准，不靠「百度能不能打开」这种会被劫持骗到的判断
- 密码用 Windows DPAPI 加密后保存，磁盘上没有明文
- 开机自启只写当前用户注册表项，不需要管理员权限
- 断线自动重连，连续失败时退避（20 → 40 → 80 → 160 秒）
- 纯标准库 + tkinter，没有第三方依赖

## 使用

1. 打开程序，填学号、密码，选登录出口
2. 勾上「开机自动启动」和「断线自动重连」
3. 点「保存并连接」

关闭窗口只是缩到系统托盘，不是退出；真正退出要点托盘图标右键菜单里的「退出」。

## 环境要求

- Windows 10 / 11
- 淮南校区（网关 `10.255.0.19`）已实测通过；合肥校区（`172.24.34.2`）代码里留了候选地址但**没有验证**
- 只适用于 Dr.COM 认证环境

## 已知情况

- 没做代码签名，首次运行会被 SmartScreen 拦一下，点「更多信息 → 仍要运行」，个别杀软也可能对 PyInstaller 产物误报
- 卸载不会删除 `%LOCALAPPDATA%\AUSTNET\` 里的配置和日志，重装还能接着用，想彻底清掉手工删掉那个目录
- 认证协议来自对本校网关的实际抓包，学校如果换认证系统或加验证码就需要跟着改
