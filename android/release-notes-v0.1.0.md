安徽理工大学校园网安卓客户端。装上之后打开就自动认证，不用再开浏览器输一遍账号密码。

## 下载

| 文件 | 说明 |
| --- | --- |
| `austnet.apk` | 直接安装。系统会提示「未知来源」，允许即可 |

## 功能

- **打开即连**：自动检测校园网并认证，不需要点任何按钮；从后台切回来也会重跑
- **两个校区自动识别**：淮南（`10.255.0.19`）和合肥（`172.24.34.2`）同时探测
- **已在线就跳过**：不会对着网关重复发登录请求
- **密码加密保存**：用 Android Keystore 的 AES-GCM，密钥由系统保管，不随应用数据备份
- **八种底色可选**：樱粉、薄荷、天蓝、薰衣草、奶油、蜜桃、石墨、云白
- **权限极简**：只要 `INTERNET` 和 `ACCESS_NETWORK_STATE`，**不申请定位**

## 使用

1. 连上校园网无线（如 `AUST Student`）
2. 打开 AUST网络，填学号、密码，选登录出口
3. 点一次「连接」保存，之后每次打开都会自动连

## 环境要求

- Android 8.0 及以上
- 只适用于 Dr.COM 认证环境

## 注意事项

**随机 MAC**：iOS 14+ / Android 10+ 默认对每个 SSID 使用随机 MAC。如果学校按 MAC 绑定
账号，会认证失败。解决方法是到 WLAN 设置里把该网络的隐私选项改成「使用设备 MAC」。

**VPN**：装着 Clash 之类的工具时，应用会把请求绑定到无线网卡绕开它，日志里会提示
「检测到 VPN」。如果仍然失败，先关掉 VPN 再试。

**合肥校区未验证**：`172.24.34.2` 这条路径只写了地址和探测逻辑，没有实测过。

**没有的功能**：断线自动重连、后台常驻、开机自启——安卓版刻意不做这些，换来的是不需要
前台服务和电池白名单。
